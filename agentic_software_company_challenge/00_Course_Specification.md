# Agentic Software Company Challenge

## Course Specification

**Format:** Bachelor elective project  
**Duration:** 12 Mondays, 10:00–16:00  
**Team size:** 4 students per company  
**Assessment:** No grading  

## Guiding Question

> How do we design, operate and improve a software company in which humans and AI agents work together as one organization?

## Core Idea

Each team forms a small software company. The company has four human employees, a shared ERPNext instance, a GitHub repository, access to a local LLM and an agent runtime.

The company must cover ten organizational functions although only four humans are available. Teams therefore need to design a mixed organization in which selected responsibilities are delegated to AI employees.

## Mandatory Company Functions

1. Managing Director
2. Account Manager
3. Requirements Engineer / Product Owner
4. Project Manager
5. Software Architect
6. Backend Engineer
7. Frontend Engineer
8. QA Engineer
9. DevOps Engineer
10. Security & Compliance Officer

A function may be covered by a human, an agent or a mixed human-agent role.

## Learning Goals

Students should be able to:

- design role-based human-agent organizations;
- implement tool-using AI agents;
- define permissions, authority and escalation rules;
- coordinate human-agent and agent-agent workflows;
- use shared organizational memory and business systems;
- evaluate agent performance empirically;
- reason about trust, autonomy, risk and accountability;
- compare human effort, agent compute and rework;
- reorganize an agentic organization based on evidence.

## Shared Infrastructure

- ERPNext / Frappe as company operating system
- GitHub as engineering platform
- Python and FastAPI for the customer product
- PostgreSQL for the customer product
- Docker for reproducible deployment
- Local LLM via Ollama or vLLM
- Optional LangGraph for agent orchestration

## Course Rhythm

Each Monday follows a common structure:

- 10:00–10:30: CEO / Customer Briefing
- 10:30–12:30: Company Sprint I
- 12:30–13:00: Break
- 13:00–13:20: Micro Lecture
- 13:20–15:15: Company Sprint II
- 15:15–15:40: Integration / Evidence
- 15:40–16:00: Board Minute / Review

## Course Arc

1. Found the Company
2. Win the Contract
3. Build the Digital Workforce
4. MVP Sprint
5. Growth and Competing Priorities
6. Customer Review / Board Meeting
7. Autonomous Company Day
8. Second Customer
9. Security Incident
10. Autonomous Enterprise
11. Science Day
12. Annual General Meeting

## Principle

The goal is not to maximize automation. The goal is to discover where humans, agents and mixed teams perform best.
