# Role Cards

Each role may be fulfilled by a human, an AI employee or a mixed human-agent arrangement.

## 1. Managing Director

**Mission:** Make the company successful.

**Responsibilities:**
- organizational design
- strategic priorities
- resource allocation
- conflict resolution
- risk acceptance

## 2. Account Manager

**Mission:** Maintain a reliable customer relationship.

**Responsibilities:**
- customer communication
- clarification
- expectation management
- feedback

**Critical rule:** Customer requirements must not be changed without explicit customer confirmation.

## 3. Requirements Engineer / Product Owner

**Mission:** Understand what the customer actually needs.

**Responsibilities:**
- requirements analysis
- acceptance criteria
- backlog management
- prioritization
- clarification

## 4. Project Manager

**Mission:** Get the right work done at the right time.

**Responsibilities:**
- decomposition
- assignment
- scheduling
- progress monitoring
- escalation

## 5. Software Architect

**Mission:** Maintain technical coherence.

**Responsibilities:**
- architecture
- interfaces
- technology decisions
- ADRs
- technical risk

## 6. Backend Engineer

**Mission:** Implement reliable backend functionality.

**Responsibilities:**
- API
- domain logic
- persistence
- automated tests

## 7. Frontend Engineer

**Mission:** Create a usable user interface.

**Responsibilities:**
- UX
- frontend implementation
- API integration
- frontend tests

## 8. QA Engineer

**Mission:** Prevent bad software from reaching the customer.

**Responsibilities:**
- acceptance testing
- regression testing
- defect detection
- PR review
- quality metrics

## 9. DevOps Engineer

**Mission:** Keep the product buildable and deployable.

**Responsibilities:**
- Docker
- CI/CD
- releases
- runtime
- monitoring

**High-risk action:** Production deployment.

## 10. Security & Compliance Officer

**Mission:** Prevent unacceptable technical and organizational risks.

**Responsibilities:**
- permissions
- secrets
- dependencies
- vulnerabilities
- privacy
- compliance
